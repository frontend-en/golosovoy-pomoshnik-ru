# Голосовой помощник RU

Минимальное расширение для Google Chrome на Windows 11: озвучивает выделенный текст и превращает русскую речь в текст.

## Установка

1. Распакуйте ZIP-архив в отдельную папку. Не удаляйте её после установки.
2. Откройте в Chrome адрес `chrome://extensions`.
3. Включите переключатель **Режим разработчика** справа сверху.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите распакованную папку `ru-voice-assistant` — ту, где лежит `manifest.json`.
6. При желании закрепите расширение через значок пазла на панели Chrome.

Chrome не устанавливает локальные ZIP-файлы напрямую: архив нужно сначала распаковать. Сам ZIP также подходит для загрузки исходников в Chrome Web Store.

После обновления файлов уже установленного расширения откройте `chrome://extensions` и нажмите **Перезагрузить** на карточке «Голосовой помощник RU». Обновите открытые веб-страницы, чтобы они загрузили новую версию скрипта расширения.

## Как пользоваться

### Текст → речь

1. Выделите текст на любой обычной веб-странице.
2. Нажмите правой кнопкой мыши.
3. Откройте **Голосовой помощник RU → Озвучить выделенное**.

Озвучивание продолжится при переключении вкладки или сворачивании Chrome. Новое выделение или снятие выделения не прерывает чтение исходного текста, в том числе при выделении в другой вкладке. Чтобы заменить читаемый текст, выделите новый фрагмент и снова выберите **Озвучить выделенное** или нажмите `Ctrl+Shift+9`. Пауза, продолжение, остановка, скорость и голос доступны через значок расширения. При смене выделения на паузе сохраняется исходный текст для продолжения чтения.

Начиная с версии **1.1.1**, настройка автоостановки при новом выделении удалена. Её сохранённое значение из предыдущей версии больше не влияет на чтение.

### Речь → текст

Самый быстрый способ:

1. Поставьте курсор в текстовое поле на странице.
2. Одновременно удерживайте `Ctrl + Alt` и говорите.
3. Отпустите любую из двух клавиш — расширение завершит распознавание и вставит текст.

Комбинация работает только внутри обычной веб-страницы. Она не перехватывает адресную строку браузера и другие приложения Windows. Быструю диктовку можно отключить во всплывающих настройках расширения.

Обычный режим без удерживания клавиш:

1. Поставьте курсор в `input`, `textarea` или другое редактируемое поле.
2. Нажмите правой кнопкой мыши внутри поля.
3. Выберите **Голосовой помощник RU → Начать диктовку сюда**.
4. Разрешите доступ к микрофону, если Chrome спросит.
5. Говорите по-русски. Нажмите `Esc` или кнопку **Стоп**, чтобы закончить.

Поддерживаются команды: «точка», «запятая», «вопросительный знак», «восклицательный знак», «двоеточие», «точка с запятой», «новая строка». Их можно отключить в настройках.

## Горячие клавиши

- удерживать `Ctrl + Alt` — push-to-talk: говорить, затем отпустить для вставки;
- `Ctrl+Shift+9` — озвучить выделение;
- `Ctrl+Shift+8` — начать или остановить диктовку;
- `Ctrl+Shift+0` — остановить всё.

Изменить сочетания можно на странице `chrome://extensions/shortcuts`.

## Русские голоса Windows 11

Расширение использует голоса Windows через Chrome. Если в списке нет русского голоса:

1. Откройте **Параметры Windows → Время и язык → Речь**.
2. В разделе голосов добавьте русский языковой пакет и голос.
3. Полностью перезапустите Chrome.

## Важные ограничения

- Контекстное меню работает внутри Chrome, а не в Проводнике и других программах Windows.
- Для push-to-talk расширение загружается на обычных HTTP/HTTPS-страницах, чтобы видеть нажатие и отпускание клавиш. Код выполняется локально и не отправляет содержимое страниц на собственные серверы.
- Windows воспринимает `Ctrl + Alt` как эквивалент `AltGr`. Если сочетание мешает вводу специальных символов, отключите push-to-talk в настройках расширения.
- Chrome запрещает расширениям работать на внутренних страницах вроде `chrome://settings` и в Chrome Web Store.
- Диктовка использует Web Speech API Chrome. Обычно звук обрабатывается онлайн сервисом распознавания, поэтому нужен интернет.
- В защищённые поля паролей диктовка намеренно не вставляет текст.
- Некоторые сайты со сложными собственными редакторами могут обрабатывать вставку текста нестандартно.

## Приватность

Расширение не содержит аналитики, рекламы и собственных сетевых запросов. Настройки хранятся средствами Chrome. Озвучивание выполняется голосовым движком Windows/Chrome. При диктовке аудио обрабатывается службой распознавания речи Chrome; правила этой обработки определяются Google Chrome.

# Конфиденциальность

**Голосовой помощник RU** не собирает, не сохраняет и не продаёт пользовательские данные.

- Выделенный текст передаётся только встроенному в Chrome механизму синтеза речи.
- Настройки голоса и скорости хранятся в локальном профиле Chrome и синхронизируются Chrome, если синхронизация включена у пользователя.
- Расширение не содержит аналитики, рекламы и собственных серверов.
- Диктовка использует встроенный Web Speech API браузера. Chrome может передавать аудио своей службе распознавания речи. Это регулируется политикой конфиденциальности и настройками Google Chrome.
- Расширение запрашивает доступ к активной вкладке только после явного действия пользователя: команды контекстного меню, кнопки или горячей клавиши.
- На обычных HTTP/HTTPS-страницах локальный сценарий отслеживает только выделение текста и состояние клавиш `Ctrl`/`Alt`, необходимые для автоматической остановки озвучивания и режима push-to-talk. Содержимое страниц не собирается и не отправляется на серверы разработчика.
